# Сайт приватного юриста

**Живе демо:** https://andreyvalko01-pixel.github.io/pravo-yurist/

Односторінковий сайт юриста: послуги, етапи роботи, контакти, FAQ і запис на консультацію.

![Головна](screenshots/desktop.png)

## Можливості

- Картки послуг з модальним вікном цін і переходом одразу до запису з потрібною темою
- Форма запису в `<dialog>`: маска телефону `+38 (0XX) XXX XX XX`, перевірка полів, згода на обробку даних
- Відправка заявок через Formspree; якщо сервіс недоступний — заявка зберігається в `localStorage`, щоб не загубилась
- Лічильники в блоці «Про мене», плавна поява блоків (вимикається при `prefers-reduced-motion`)
- Розмітка Schema.org `LegalService` для пошукових систем
- Адаптив, мобільне меню

## Запуск

Збирати нічого не треба — відкрити `index.html` або запустити будь-який статичний сервер:

```bash
npx serve .
```

## Налаштування форми

1. Створити форму на [formspree.io](https://formspree.io).
2. Вставити її адресу в `FORM_ENDPOINT` у `js/form.js`.

## Файли

```
index.html
css/main.css
js/services.js  — тексти та ціни для вікон послуг
js/form.js      — маска телефону, валідація, відправка
js/main.js      — меню, модалки, лічильники, анімації
```
